# Retail Sales & Customer Analysis

## Project Overview

An end-to-end retail data analysis project using Python to explore customer behavior, product performance, store-type performance, and transaction patterns.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Objectives

- Analyze retail transaction and customer data
- Understand sales performance across product categories and store types
- Explore customer demographics and purchasing behavior
- Identify transaction patterns and business insights
- Present findings through data visualizations

## Analysis Performed

- Data loading and exploration
- Data cleaning and data-type conversion
- Dataset integration using Pandas
- Missing-value analysis
- Descriptive statistics
- Customer and demographic analysis
- Product-category analysis
- Store-type performance analysis
- Transaction pattern analysis
- Data visualization using Matplotlib and Seaborn

## Key Areas of Analysis

- Customer distribution by city
- Sales performance by store type
- Product-category performance
- Gender-based purchasing patterns
- Customer transaction behavior
- Age-based customer analysis
- Transaction and return/refund patterns

## Project Dataset

The project works with customer, transaction, and product-category data and combines these datasets for exploratory analysis.

## Project Outcome

The analysis demonstrates an end-to-end Python data analytics workflow, from data preparation and integration to exploratory analysis, visualization, and business-focused interpretation.

## Skills Demonstrated

**Python | Pandas | NumPy | Data Cleaning | Exploratory Data Analysis | Data Visualization | Matplotlib | Seaborn | Business Analysis**
